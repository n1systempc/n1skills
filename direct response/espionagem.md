QUEBRAR CLOAKER

1- no anúncio, clique em ver detalhes
olhe um por um e veja se tem algum domínio diferente, se tiver abra
faça isso também com anúncios com menos duplicações

2- clique com botão direito em saiba mais e copia o link, depois cole no navegador
dentro desse monte de letras, encontre algo parecido com um domínio e também parecido com uma slug
pegue o que você achou e junte, assim você descobriu o link real da oferta

3- abra o site do gov.br, aperte control shift i e selecione a opção de celular, depois cole o link da oferta
assim você vai ver a oferta como se estivesse no celular

4- abra o saveweb2zip
coloque a url e marque a opção copy mobile

5- Interaja com a página dele
curta fotos, veja os vídeos
depois de alguns minutos vai começar a aparecer o anúncio dele pra você

COMO NÃO SER CLONADO?

1- crie outra campanha, ex: campanha do preju
porém tem que ser uma conta já aquecida, se fizer isso numa conta fajuta, cai na hora
- troque o domínio, ex: igorsantos.com - igorsantos1.com
- troque por uma estrutura que não deu em nada
- duplique 100 conjuntos com custo de 0,01

2- coloque um backredirect em todas os domínios
no seu elementor, adicione o widget HTML na sua página e cole o código
em https://linkdocheckout.com, troque pelo seu checkout

<script>
window.onload = function() {
    var anchors = document.getElementsByTagName("a");

    for (var i = 0; 1 < anchors.length; i++) {
        anchors[i].href = "https://linkdocheckout.com"
    }
}
</script>

3- troque o link de exibição
não deixe vazio, coloque algo relacionado a oferta, tipo: www.crochekids.com
